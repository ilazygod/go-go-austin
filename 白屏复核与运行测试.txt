Origin null is not allowed by Access-Control-Allow-Origin. Status code: 0
Failed to load resource: Origin null is not allowed by Access-Control-Allow-Origin. Status code: 0
以上各一对，分别关联 manifest.json、assets/index-_cXWuQUN.js、assets/index-BZhK9d-s.css（共 6 条）。
另有：Not allowed to load local resource: file:///favicon.ico（第 7 条，标签页图标）。
模块主脚本被阻断使 React 无法挂载，是白屏的直接原因；同时 CSS 和 manifest 也被阻断。没有禁用 CORS、文件安全或其他浏览器保护。
截图与控制台记录：Safari-file协议白屏.png、Safari-file控制台.txt。
原部署版必须以 HTTP/HTTPS 运行。这符合浏览器模块的本地文件限制说明：
https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Modules
